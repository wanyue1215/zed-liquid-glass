# Liquid Glass for Zed

A dark theme inspired by the layered materials of Apple Liquid Glass: frosted window backgrounds, translucent navigation, soft borders, blue selections, and a quieter code palette.

## Install locally

1. Open Zed's Extensions page.
2. Choose **Install Dev Extension** and select this directory.
3. Open the theme selector and choose **Liquid Glass Dark**.

The theme is self-contained and does not require the Glass extension or settings overrides. It does not change editor preferences, fonts, keybindings, or system settings.

## Appearance

- Blurred, translucent window background on supported platforms.
- Darker editor and terminal surfaces for readable text.
- Dark RGB panel tint keeps pinned project-tree folders dark when Zed makes their background opaque.
- Soft highlights and blue focus/selection states.
- Pink keywords, lavender functions, and muted green strings.

This theme approximates the look with Zed's theme API. It does not implement native Liquid Glass refraction or animated materials. Blur and transparency depend on the platform and system accessibility settings.
